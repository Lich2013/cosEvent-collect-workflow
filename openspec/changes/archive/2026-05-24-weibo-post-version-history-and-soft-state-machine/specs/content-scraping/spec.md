## ADDED Requirements

### Requirement: 微博二次编辑版本控制与发布时间重锚
为了无损保留微博二次编辑的正文历史痕迹，并物理解决置顶微博因跨年编辑导致大模型相对日期推导时间轴倒流的问题，系统**必须且 SHALL**在爬虫抓取拦截阶段实施版本控制与时间重锚：
1. **后缀版本化**：一旦检测到当前微博正文存在编辑次数（`edit_count > 0`），系统**必须且 SHALL**将抓取出的 `post_id` 重写拼装为 `原始post_id#v{edit_count}` 的后缀格式，以使其在数据库 `raw_posts` 的 `UNIQUE(platform, post_id)` 联合约束中成为全新记录并直接 `INSERT` 存档。
2. **发布时间重锚**：对于所有被判定为二次编辑版的博文记录，系统**必须且 SHALL**将其 `published_at`（发布时间）字段强制改写并重锚（Re-anchor）为当前抓取时的东八区北京时间（`YYYY-MM-DD HH:MM:SS`），从而将大模型语义推算时间锚点彻底拉回编辑发生的新起点，确保“下周末”等描述计算年份精准。

#### Scenario: 成功提取并插入包含版本后缀的二次编辑博文且重锚发布时间
- **WHEN** 抓取到的微博存在二次编辑（`edit_count = 1`）且触发保存入库时
- **THEN** 该记录在数据库 `raw_posts` 中以 `post_id#v1` 的后缀新增一行独立纪录存档，且其对应的 `published_at` 字段被强制写入并锁死为当前的北京抓取时间。
