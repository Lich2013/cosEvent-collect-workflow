## ADDED Requirements

### Requirement: 只读看板对 '未知' 日程的超级节点时间继承
控制台 `summary` 看板与 `calendar` 日历看板在展现 Coser 具体日程时，必须且 SHALL 支持对 '未知' 日期的日程实时、动态地继承并展示其关联超级漫展的最宽举办时间。
1. **时间推算继承规则**：如果 Coser 某一单体日程的 `event_date` 在数据库中为 `'未知'`，但该日程所关联的归一化超级漫展节点（`normalized_events`）的 `start_date` 和 `end_date` 已经被其他 Coser 标定为有效日期：
   - 看板在打印展现时，系统 SHALL 自动动态继承超级漫展的日期范围，并进行格式化输出。
2. **视觉打标提示**：
   - 展现被继承推算的日期时，系统 MUST 尾随拼接显示 `(推算自超级节点)` 字样，以向用户明确区分原始真实描述与推算所得的日程脉络。

#### Scenario: 成功在日历与日程看板中实时继承并渲染推算日期
- **WHEN** Coser A 的 CP30 日程在数据库中为 '未知' 日期，但 CP30 超级节点已被其他 Coser 标定举办日期为 `2026-05-02 至 2026-05-03`，用户运行 `cosevent summary --by-event` 时
- **THEN** 控制台在该 Coser 参展日程下成功回显 "参展日期: 2026-05-02 至 2026-05-03 (推算自超级节点)" 且退出状态码为 0
