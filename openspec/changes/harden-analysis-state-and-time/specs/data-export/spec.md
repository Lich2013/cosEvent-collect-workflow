## ADDED Requirements

### Requirement: 导出范围必须使用统一可测试参考日期
系统在执行 `scope = future` 的导出和查询过滤时，必须且 SHALL 使用统一北京时间参考时钟计算当前日期。测试必须能够冻结该参考日期，使历史、未来与未知日期过滤在任意真实运行日期下保持确定性。

#### Scenario: 冻结日期下导出 future 范围稳定
- **WHEN** 测试将统一参考日期冻结为 `2026-05-25`，数据库包含 `2025-09-20`、`2026-07-01`、`未知` 和一个 `已取消` 活动
- **THEN** `scope = future` 导出仅包含 `2026-07-01` 与 `未知` 两条未取消活动

#### Scenario: 真实日期变化不影响冻结测试结果
- **WHEN** 运行测试当天真实系统日期晚于测试数据中的未来活动日期，但测试已冻结参考日期
- **THEN** 导出过滤结果仍以冻结参考日期为准，不受真实系统日期影响

### Requirement: 日历视图未来范围使用同一参考日期
系统在导出或查询 calendar 视图时，必须且 SHALL 使用与默认排班导出相同的统一北京时间参考日期过滤未来超级节点，避免 default 视图与 calendar 视图在同一次运行中使用不同时间基准。

#### Scenario: default 与 calendar future 过滤日期一致
- **WHEN** 统一参考日期为 `2026-05-25`，用户分别执行 default 导出和 calendar 导出
- **THEN** 两种视图对未来范围的日期判断均以 `2026-05-25` 为边界
